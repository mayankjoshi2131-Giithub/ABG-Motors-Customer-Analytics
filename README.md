# ABG Motors — Customer Analytics & Predictive Insights

A data analytics and visualization project focused on understanding
customer behaviour, purchase probability and high-potential customer
segments for ABG Motors.

## 📌 Project Overview

The project analyzes customer-level data to identify demographic
patterns, purchasing behaviour and potential customers.

The analysis combines Python-based data analysis with interactive
Tableau dashboards to transform raw customer data into actionable
business insights.

## 🎯 Objectives

- Analyze customer demographics
- Study customer income and age groups
- Analyze purchase probability
- Identify potential and high-priority customers
- Segment customers based on key characteristics
- Build interactive Tableau dashboards
- Generate data-driven marketing insights

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- SQL
- Tableau
- Jupyter Notebook

## 📊 Key Analysis

The project focuses on:

- Customer demographics
- Age-group analysis
- Gender distribution
- Income segmentation
- Purchase probability
- Predicted purchase behaviour
- High-priority customer identification
- Customer segmentation
